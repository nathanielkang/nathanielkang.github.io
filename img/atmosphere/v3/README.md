# Slideshow assets, November 2026

The nine WebP background plates were restored with the built-in ImageGen tool from the existing SOCAL Lab slideshow and its earlier drafts. Equations and captions are separate from the photographs. Original assets remain in the parent directory.

The SVG equations were typeset from `equations.json` with MathJax 4 and the MathJax-Fira font package 4.1.3, then exported as standalone paths. No math rendering library or additional math font is downloaded by visitors. The two `-mobile.svg` variants use line breaks for narrower screens.

Font sources: https://github.com/firamath/firamath and https://github.com/mathjax/MathJax-fonts. MathJax source: https://github.com/mathjax/MathJax-src. License notices are in `licenses/`.
